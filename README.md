# 個人情報コード化ツール

児童生徒の氏名・学年・組・番号をコードへ置き換え、文書を扱う前の個人情報確認を支援するWindows向けアプリです。名簿をパスワードで暗号化して保存し、コード化した文書を元の氏名へ戻せます。

## 起動

Python 3.14を用意し、このフォルダで以下を実行します。必要な部品の取得時はインターネット接続が必要です。

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app\main.py
```

準備後は `起動.bat` から開けます。アプリ内の処理は端末内で完結します。

1. 初回に自分で保存用パスワードを決めます。
2. 「名簿登録」でCSVまたはExcelの名簿を読み込みます。`sample/roster.csv` は、この公開版のために作った架空の見本です。
3. 「コード化」で文書を開き、確認が必要な候補を選んで別ファイルへ保存します。
4. 「元に戻す」でコード化した文書を読み、同じ名簿を使って復元します。

## 対応範囲と制限

テキスト・CSV・Excel・Word・PDFを読み込みます。WordとPDFは文字を取り出したMarkdownとして保存するため、元の見た目や画像は戻りません。

- 学年1〜9、組1〜20、番号1〜1000が対象です。
- 氏名・学年・組・番号以外の住所、病歴、家庭情報などは自動で消しません。
- 固定コードは、候補の名簿とプログラムを持つ相手からの特定まで防ぐ完全な匿名化ではありません。
- `3年`・`2組`・`1番`など意味が複数ある表記は、画面で確認してから置き換えます。
- 暗号化された対応表は `data/master.enc` に保存します。元の名簿や対応表は公開・共有しないでください。

元版の記録では自動確認76件とWindows実行ファイルの起動確認が成功しています。実画面の見た目・操作確認は未完了です。この公開用コピーでは動作確認を実行していません。
